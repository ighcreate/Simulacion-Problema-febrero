# Simulación del Problema 1 - Examen de Febrero

Este proyecto contiene la simulación del problema 1 del examen de febrero. Incluye el caso base y varios scripts adicionales para ver cómo influyen los cambios de parámetros y los casos límite en el comportamiento del sistema.

Para ejecutar los programas es necesario instalar las librerías necesarias, disponibles en requirements.txt


### 3. Ejecutar las simulaciones
Para ver la simulación base del problema, ejecuta el archivo simulacion.py

También se pueden ver los diferentes casos ejecutando cualquiera de los otros archivos:
simulacion_g_cero.py (Simulación sin gravedad)
simulacion_k_infinito.py (Simulación con constante k infinita)
simulacion_l_cero.p (Simulación con longitud cero)
simulacion_masa_pendulo_dominante.py (Simulación con masa del péndulo dominante)
simulacion_x0_cero.py (Simulación con posición inicial en cero)
